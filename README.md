# Financial Health Dashboard

## Project Overview
The Financial Health Dashboard is an interactive Power BI dashboard designed to analyze financial transaction data and provide meaningful business insights.

## Dataset Information
- FactTransaction
- DimAccount
- DimCustomer
- DimCustomerUSA
- DimProduct
- DimProductCategory
- DimProductSubCategory

## Tools Used
- Power BI
- CSV Dataset
- Data Modeling
- Data Visualization

## Dashboard Features
- Total Transactions KPI
- Total Transaction Amount KPI
- Total Accounts KPI
- Transactions by Status
- Transaction Amount by Status
- Transaction Trend Over Time

## Key Insights
- Most transactions were successful.
- Successful transactions contributed the highest transaction amount.
- Total transaction amount exceeded 5 million.
- Transaction trends can be monitored effectively over time.

## Files Included
- Financial_Health_Dashboard.pbix
- Task1_Report.pdf
- Dataset Files
- Dashboard Screenshots

## Conclusion
This dashboard successfully transforms raw financial transaction data into meaningful insights using Power BI. The visualizations help analyze transaction performance, account activity, and financial trends effectively.
